# Cold Chain Warehouse Location

Computational supplement for **Robust Cold-Chain Warehouse Location Selection Under Uncertainty: An Integrated Spherical Fuzzy and Multi-Method Decision Framework**, Hüseyin Ali Sarıkaya, Mudanya University. Release 2.0.0, 31 October 2026.

The package reproduces the author's approved manuscript: 15 Ankara districts, 13 criteria, five equally weighted active practitioners, spherical fuzzy weighting, EDAS, WASPAS, CoCoSo, TOPSIS and VIKOR. It retains the approved manuscript and its original architecture illustration unchanged.

## Run the study

Use Python 3.12. From the folder containing `run_analysis.py`:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python run_analysis.py
python scripts/check_reproduction.py
python scripts/build_supplement.py
```

The first command requires internet access to install dependencies. All subsequent analysis runs use local inputs. No account, solver licence, API key, or external data request is needed. The analysis generates a `results/` folder. Running it again overwrites generated files in that folder; the supplied inputs and `reference_results/` remain intact. Use `--output another_folder` to retain a separate run, followed by `python scripts/check_reproduction.py --results another_folder`.

GitHub can run the same sequence through `.github/workflows/reproduce.yml`. After uploading the extracted project contents to the repository root, select **Actions → Reproduce manuscript results → Run workflow**. Download **cold-chain-reproduced-results** from the completed run. See the detailed Turkish guide in `docs/github_tr.md` and `docs/GitHub_Kullanim_Rehberi.docx`.

## Interpretation and provenance

The five practitioners are real professionals with relevant practical experience. Their anonymous departmental profiles are in `data/practitioners.csv`. Their weights are equal at 0.20. The primary matrices use the upper-triangular assessments and reciprocal lower-triangular encoding specified in the manuscript; `provenance/pairwise_encoding_log.csv` records the four encoding changes relative to the supplied comparison file. The original workbook is retained unchanged for source traceability. Its historical result sheets are not the release result tables; use `reference_results/` and the newly generated `results/` for the approved analysis.

Population integers are the values underlying the supplied full-precision C10 workforce proxy; no new population observations have been introduced. C10–C13 are recalculated in `derive_inputs`. The working-age share is evaluated as the decimal ratio 685/1000 to avoid intermediate binary rounding. Inputs C1–C9 are unchanged. The reporting duration of the shipment totals is unspecified, so load and emission units refer to the recorded load period.

Method score ties use average ranks. Borda ties are resolved by first-place counts, top-three counts, lower worst rank, then fixed alternative order. Criterion deletion physically removes the columns before method-specific normalisation. Across-method SD uses the population definition; Monte Carlo SD uses the sample definition. The 95% rank interval contains the empirical 2.5% and 97.5% quantiles, with nearest observed rank selection.

The probabilities quantify weight uncertainty conditional on fixed performance data and concentration 200. The exposure and emission indicators are comparative proxies. The district shortlist supports subsequent parcel and network feasibility analysis. These interpretations follow the approved manuscript.

## Environment and verification

`requirements.txt` pins the analysis and document dependencies. `reference_results/metadata.json` records the tested Python and library versions, input hashes, seed and statistical checks. `python scripts/check_reproduction.py` checks full-precision CSV results within relative tolerance 1e-11 and absolute tolerance 1e-12, and checks all displayed manuscript tables exactly. Plot pixels may vary with fonts on another operating system; the original architecture must always remain byte-identical.

Changing inputs, parameters, simulation count or seed intentionally changes the results and will normally fail comparison to this frozen release. Keep the default settings to reproduce the manuscript. A custom simulation count is available with `python run_analysis.py --simulations 1000 --output exploratory_results`.
